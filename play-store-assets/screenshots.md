# Screenshots

Required Play Store screenshot groups:

- Phone (up to 8 screenshots, 1080x1920 or similar)
  - Home with quick-access cards
  - Tool grid / categories
  - PDF tool result
  - Notes list + editor
  - Compass / emergency / weather / messaging
  - Settings + backup restore

- 7-inch tablet (optional)
- 10-inch tablet (optional)

Create subfolders `phone/`, `tablet-7/`, `tablet-10/` with PNG/JPEG screenshots.

# OFA — One For All

OFA is a local-first Android utility suite built with Kotlin and Jetpack Compose/Material You.

Package: `org.phireox.ofa`

> OFA is an independent app and is not affiliated with or endorsed by My Hero Academia, Shueisha, or any other rights holder.

## Build

```bash
./gradlew assembleDebug
```

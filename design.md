# OFA — Design

## Principle

OFA should look like it was designed by a small, thoughtful product team — not generated from a startup UI template.

Every element answers: «Why is this here?» No strong answer → remove it.

## Visual Direction

quiet · technical · human · editorial · precise · minimal · mature · fast · uncluttered

Inspired by the restraint of helium.computer. Original OFA design.

## Color System

Light mode:
  Background: #fafafa  Primary text: #0a0a0a
  Secondary: #737373   Border: #e5e5e5

Dark mode:
  Background: #0a0a0a  Primary text: #fafafa
  Secondary: #a3a3a3   Border: #262626

Status colors (sparingly): Success #16a34a · Warning #ca8a04 · Error #dc2626

## Typography

- System font stack
- Headings: compact
- Paragraphs: 16–18px, 1.5–1.6 line-height
- Labels: short · Buttons: direct
- Numbers: highly legible (tabular-nums)

## Motion

Sparse. Only for connecting, transfer progress, item insertion/removal, state transitions.
Respect prefers-reduced-motion.

## Microcopy

Send files · Receive files · Connect device · Drop files here · Choose files
Waiting for connection · Connecting · Connected · Transferring ·
Transfer complete · Cancelled · Expired · Connection lost · Try again

Never: Unlock · Supercharge · Boost · Magic · Next-gen · Revolutionary ·
Seamless · AI-powered · Smart transfer · Ultra-secure · Military-grade

## Error Copy

Always explain next action:
- "The other device is no longer connected. Create a new transfer and try again."
- Not: "Connection failed." or "ERR_RTC_SIGNAL_004"
